5. Source `K1D18C` establishes the actual rank-one Clifford-generator conjugation matrix and determinant -1; `K1D18D` bridges that actual matrix with Clifford conjugation **under a displayed two-unit factorization**; `K1D18E` establishes det +1 conditionally for an actual two-generator source factorization. `K1D18F/G/H` package actual Lipschitz action and real-linear equivalences. 6. Source `CliffordAlgebra.star_ι` in pinned `Mathlib/LinearAlgebra/CliffordAlgebra/Star.lean` has `star (ι Q v) = -ι Q v`. Consequently, **do not assert that an individual positive-square odd generator is unitary/pin**; the even two-generator Clifford word requires its own exact star/unitary and even-grade proof. Conjugation by a single odd Clifford unit is a Lipschitz action, not automatically a Spin action. Verify all signs/order against original S1V37 matrix and S1V31 source action.
