## 5. Plan and discriminating tests

The experiment is **E-TD-C1A-D0-NATIVE-BOUNDARY-001**, a diagnostic-only collection. It does not replace full strict qualification.

Phase A, after building only original Core and the frozen generic evaluation helper:
1. Metadata: synthesize native module/normed structures; partially specialize the existing generic lemmas and print their explicit public types.
2. Primitive control: continuous-operator coercion on a variable original Fock isometry.
3. Existing generic bridge specialized to original Fock with variable U/A/B and an explicit pointwise/operational premise.
4. New small helper: prove the two conversion lemmas directly on the literal original Fermion 2 carrier, with variable U/A/B. This follows NORM-0B's fixed-carrier/arbitrary-data pattern.

If the primitive control or fixed-carrier helper fails, collect the result and stop **before** the expensive original axis dependency build. Do not repeatedly try the native composite proof.

Phase B, only if the primitive and fixed-carrier checks compile/audit:
5. Direct source axis control, copied in its exact original pointwise form.
6. Coercion of the actual original G4E gauge isometry with no gamma data.
7. Axis-to-operator join using the new native helper and typed local U/A/B/source witness.
8. Conditional final evaluation with actual G4E and gamma data, comparing the frozen generic helper against the native-fixed helper. The operator identity is an **explicit hypothesis** in these evaluation diagnostics and is not claimed proved.

Every case is a separate file/process with its own bounded compiler time, full log, return code, axiom/warning audit and elapsed duration. A failure in one candidate must not prevent collection of the other independent cases. Required controls failing yields a diagnostic obstruction, never qualification.

Use bounded trace_state on source-witness/goal boundaries and ordinary #synth/#check, following the existing F1F boundary files. No pp.all, broad recursive unfolding, new axioms, sorry/admit/unsafe, resource-limit increase, new cache, or source replacement.
