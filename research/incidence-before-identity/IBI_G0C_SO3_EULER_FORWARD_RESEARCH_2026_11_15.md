## Direct constructive SO(3) ZXZ Euler donor

The public [LionSR/QICLean EulerAngles.lean](https://github.com/LionSR/QICLean/blob/603fc408b9f4c2a50f2475e1e44843fdc0a9c0ac/QICLean/Algebra/SpinCover/EulerAngles.lean), snapshot `603fc408b9f4c2a50f2475e1e44843fdc0a9c0ac`:
- `exists_cos_sin` lifts any real pair of norm one to a real angle (using the argument of a nonzero complex number).
- `so3_euler_decomp` proves `∃ α β γ, M = rotZ α * rotX β * rotZ γ` for arbitrary `M ∈ Matrix.specialOrthogonalGroup (Fin 3) ℝ`.
- `spinHalfCover_surjective_onto_SO3` uses that result and its separately proved axis generators.
- It explicitly separates the gimbal-lock branch from the nonsingular branch and derives cofactor equations from the orthogonality and determinant-one hypotheses. Direct adaptation will need a strict Lean 4.34.1 / pinned Mathlib audit; donor targets a different toolchain and remains external/unqualified for BFSS.

The three-by-three components in our conventions (`i,j=0,1,2`) are
```text
M02 =  sin(α) sin(β)
M12 = -cos(α) sin(β)
M20 =  sin(β) sin(γ)
M21 =  sin(β) cos(γ)
M22 =  cos(β)
```
Set `sβ = sqrt (1 - M22^2)`, then find `β` with `cos β = M22` and `sin β = sβ`.
- If `sβ ≠ 0`, `cos α = -M12/sβ`, `sin α = M02/sβ`, `cos γ = M21/sβ`, `sin γ = M20/sβ`. Each pair has unit norm by column/row orthogonality. Use `field_simp`, narrow `nlinarith only` and the donor's cofactor polynomial certificates for the remaining four entries.
- If `sβ = 0`, then `M22^2 = 1`, and orthogonality forces `M02=M12=M20=M21=0`. Choose `γ=0`, find `α` via `cos α = M00`, `sin α = M10`, and prove the remaining 2x2 block from determinant/cofactor identities. This covers **both** `β=0` and `β=π`; divisions by `sin β` cannot be used here.
- Do not confuse ZXZ singularity `sin β = 0` with Tait-Bryan XYZ singularity `cos β = 0`.

## Independent adversarial numerical check (NOT a Lean proof)

A deterministic xorshift-style / LCG JS harness seeded `723123` used uniformly drawn components in `[-1,1]` normalized into `20,000` unit quaternions, converted via the standard quaternion-to-rotation 3x3 matrix, then extracted/reconstructed ZXZ angles using `atan2` and `acos`.
- Random cases: maximum entrywise absolute reconstruction error `3.521315183885321e-14`; average `3.1135657881141767e-16`; `0` errors above `1e-9`.
- Exact singular control: `40` matrices at `β=0` or `β=π` with independently varied outer angles; max error `2.220446049250313e-16`.
- Near-singular control: `24` matrices with `β∈{1e-7,1e-6,1e-5,π-1e-7,π-1e-6,π-1e-5}`; max error `4.433795724167638e-11`. This shows numerical cancellation near gimbal lock, not a mathematical obstruction.
- The random cases are **not** generated by ZXZ composition, avoiding that circular test. Floating-point diagnostics cannot establish existence for every exact real matrix.
