## Evidence rules

A record ID denotes a scoped result, not a run, file, or independent theorem. Historical evidence status is separate from current file identity. Source-level declarations and #print axioms requests are lexical candidates, not an elaborated signature or a fresh axiom report. Explicit assumptions and non-implications remain in each original receipt. A direct import is not a declaration-level proof dependency; editorial scientific links are not a complete import or kernel graph. Empty edges mean unrecorded or root, not proven independence. Do not promote finite tests, empirical transcription or conditional statements from provider success. A cancelled gate is not a mathematical RED. N-05's cited run is cancelled and titled D1-B; its precise declaration/run correspondence requires successor review, not automatic promotion.
