Date: 2026-11-12 Pacific / 2026-11-13 UTC.
This is **non-Lean** audit infrastructure. No M3 mathematical theorem is qualified by it.

A dedicated inexpensive workflow enumerates all recursive `import OAI...` dependencies of the actual L6G7Z original FullL2 gauge module, the staged M3G0A source, and its independent consumer. It verifies all 96 accepted M2C1 pins; it then verifies each imported module against the immutable baseline commit `c6253c7c8bec20ede9ac9cb725fb694c5e55d6b5` using actual Git object blob hashes. The six L6G7U–Z source blobs are checked individually against their historically compiled, reviewed hashes. It also pins the Lean/Mathlib revisions.

Results are written to `bfss-m3g0a-manifest-audit/pin-manifest.json` as a CI artifact. The file contains **one path-to-blob pin per unique file**, with exact intersection counts. A failed import, hash drift, path mismatch or toolchain mismatch aborts before any Lean build. This audit is not a proof and does not verify every new declaration's typechecking; it is a preliminary manifest authority to be integrated into a dedicated strict compile/axiom consumer workflow after review.

The baseline tree sha (reachable as this exact historical commit) is an immutable path+hash reference, not the moving branch HEAD. It is not permission to alter the qualified original L6G7 source.
